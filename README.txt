بلاغ تجريبي — محاكاة غير رسمية
نسخة مستقلة غير تابعة لتطبيق كلنا أمن أو لأي جهة رسمية.

التشغيل:
ارفع جميع الملفات الموجودة بجانب index.html إلى استضافة HTTPS مثل GitHub Pages.
لا ترفع ملف ZIP نفسه: فك الضغط أولًا.
يمكن فتح index.html للمعاينة على الكمبيوتر، لكن التثبيت والعمل دون اتصال يحتاجان إلى HTTPS أو localhost.
على الآيفون: افتح رابط الموقع في Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية.

المزايا:
الجرائم التسع، حساب المبلغ عليه وحالته، رابط المشاركة والوصف.
حتى ٦ صور محفوظة مع كل بلاغ، عرضها وتكبيرها، وأرقام تجريبية عشوائية من ٧ خانات.
خريطة توضيحية تدعم السحب بكل الاتجاهات، والتكبير والتصغير، والتقريب بإصبعين، وتحديد نقطة افتراضية. ليست خريطة جغرافية.
إلغاء البلاغ مع إبقائه في السجل، أو حذفه بعد التأكيد.

البيانات:
تُحفظ البلاغات والصور في متصفح الجهاز نفسه، دون إرسالها لأي جهة.
حذف بيانات الموقع أو استخدام التصفح الخاص قد يفقد السجل.
هذه النسخة لا تنقل بياناتك بين الاستضافات أو المتصفحات المختلفة.

تحديث الوضع الداكن:
واجهة داكنة كاملة وعنوان الجرائم المعلوماتية بحجم أكبر.
نافذة تأكيد فيها رقم عشوائي من ٧ خانات وعدد المرفقات التي تم حفظها فعليًا.
الخريطة توضيحية غير جغرافية، وتعمل محليًا دون مزود خرائط خارجي.
